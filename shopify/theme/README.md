# shopify/theme/

Reserved for Phase 7 (Theme Development). Intentionally empty — no Liquid,
JSON template, or theme code is written until Phase 7 is approved (see
`docs/MIGRATION_PROGRESS.md` § Phase 6.5 Readiness Report).

When Phase 7 starts, this will hold a standard Online Store 2.0 theme
structure (`sections/`, `templates/`, `snippets/`, `layout/`, `assets/`,
`locales/`, `config/`) per `docs/SHOPIFY_CODING_STANDARDS.md`.
